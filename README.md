# Verilog HDL – Digital Design Projects

A practical learning repository focused on **Digital Electronics, Verilog HDL and RTL Design**. This repository documents my step-by-step journey of learning digital logic design through coding, simulation and practical implementation.

## About This Repository

This repository contains Verilog HDL programs, testbenches and simulation results for fundamental digital circuits.

The main objective is to strengthen my understanding of digital electronics and develop practical skills in RTL design and hardware description languages.

## Tools & Technologies

- **HDL:** Verilog
- **Code Editor:** Visual Studio Code
- **Simulator:** Icarus Verilog
- **Waveform Viewer:** VCD Viewer
- **Version Control:** Git & GitHub

## Learning Approach

Each project follows a practical workflow:

1. Understand the digital circuit and its working principle.
2. Prepare the truth table.
3. Write the Verilog design code.
4. Develop a testbench.
5. Run the simulation.
6. Verify the output using waveforms.
7. Upload the completed project to GitHub.
